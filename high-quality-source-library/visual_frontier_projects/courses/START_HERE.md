## Agent 使用顺序

1. 先按 subjects、level、visual_strength、project_strength 和 evidence_strength 过滤 course_sources.json。
2. 想持续扩库时，优先打开 RESOURCE_CURATORS.md；这些来源本身就在维护课程目录、学习路线或开放教育资源。
3. 用课程解释概念时，定位到具体课次、讲义、作业或项目页；不要只引用课程首页。
4. 课程讲解是解释源，不自动等同于同行评审证据。涉及医学、健康、法律或重大事实判断，回到指南、论文、数据与官方文件。
5. “经典归档”仍可能非常优质，但框架版本、API、统计数据与外部链接会老化，发布前必须核对当前状态。

## 评分与标签

- visual_strength：图示、演示、动画、作品等视觉密度，不代表教学质量。
- project_strength：代码、作业、实验、项目或可复现 Demo 的强度。
- evidence_strength：作为技术/事实依据的适用度。
- cost：免费预览不等于完整课程免费；以课程当前页面为准。
- course_status_check / feed_status：2026-08-19 的可访问性快照，不是永久可用承诺。

## 权利边界

课程视频、讲义、代码、作业和学生作品可能采用不同许可。优先链接原页或嵌入官方视频；截图、重剪、翻译和大段转载前，逐项核对许可并署名。
