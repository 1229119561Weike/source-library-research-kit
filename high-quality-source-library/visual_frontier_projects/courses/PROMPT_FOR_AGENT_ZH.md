# 可直接交给 Agent 的课程研究提示词

请先读取本目录中的 START_HERE.md、course_sources.json、RESOURCE_CURATORS.md 与 LEARNING_PATHS.md。

围绕【主题】和【受众水平】，筛选 6–10 个课程或学习资源：至少包含 2 个名校来源、1 个机构来源、1 个个人教学来源，并优先选择有公开视频、讲义、代码、作业或项目 Demo 的条目。若现有条目不足，可从 RESOURCE_CURATORS.md 中继续发现，但必须回到课程原页核对。

对每个候选资源：确认课程当前状态、费用、讲师、先修要求、内容日期、可用课次/讲义/代码、许可，以及能支持的具体主张。不要把讲师观点写成学界共识；不要把免费预览写成整课免费。

最后输出：

1. 推荐顺序与适合人群；
2. 每门课最值得看的具体课次/项目；
3. “概念—课程解释—一手证据—可视化 Demo—局限”表；
4. 一条高利他 X 帖或线程草稿；
5. 具体原页链接、署名与权利注意事项。
