# 高质量信源素材库｜Agent 使用入口

这是一个用于研究、选题、事实核验和 X 帖文写作的信源索引，不是可以直接当作事实引用的二手数据库。

## Agent 应先读取什么

1. `manifest.json`：文件说明、数量和分类。
2. `source_catalog.json`：机器可读主库，包含 494 个去重信源及评分、引用角色、Feed 状态、用途和核验提醒。
3. `human_guide_zh.md`：完整使用纪律和人工工作流。

## 选择来源的顺序

按任务需要依次使用：

1. **证据源**：论文、系统综述、官方文件、原始数据、数据库。
2. **解释源**：专业机构、研究者或高质量媒体的解释。
3. **观点源**：明确归因给作者，不得改写成客观事实。
4. **线索源**：只用于发现选题，必须继续追到原始材料。
5. **灵感源**：用于结构、视觉和表达灵感，不可代替事实证据。

## 强制规则

- 不要把目录条目本身当作证据；应打开具体文章、论文、数据集或官方页面。
- 发布前重新核对作者、日期、上下文、样本、方法、单位、版权和链接可用性。
- `feed_status` 只是 2026-08-17 的网络层检查，不代表内容真实，也不代表永久可用。
- 不要在帖子正文引用 RSS 地址；正文应链接具体原文或原始证据。
- “Karpathy 92”是 Karpathy 分享的 HN 2025 RSS 冷启动集，不是他逐条亲自背书的 92 个来源。
- 心理与健康内容优先指南、系统综述、专业机构和原始研究；不得据此做个体诊断、治疗建议或危机处置。
- 情商、人格和认知测量须检查量表效度、文化适用性，避免把群体平均套到个人。
- 商业和成长案例须说明相关性、幸存者偏差、激励结构、基准率与不可复制条件。

## 推荐检索字段

- `category` / `subcategory`：主题过滤。
- `citation_role`：决定来源可承担的引用责任。
- `priority` / `score`：安排阅读顺序，不代表事实真伪。
- `feed_status`：判断是否适合自动订阅。
- `x_use`：可转化的 X 帖型。
- `why`：收录理由。
- `verify_note` / `validation_note`：风险、版权和核验提醒。
- `homepage` / `feed_url_canonical`：入口；具体主张仍需找到具体内容页。

## 建议输出结构

当用户要求写 X 帖文时，先提供：

1. 一句话受众收益。
2. 核心结论及置信度。
3. 至少一个证据源；必要时再加解释源。
4. 限制、反例或不确定性。
5. 可执行建议。
6. 具体原文链接，而不是本目录或 Feed 链接。

如果任务涉及“最新、今日、目前、热门、价格、政策或研究进展”，必须联网重新核验，不能只依赖本包快照。
