# 可直接复制给 Agent 的提示词

请先完整读取本包中的 `START_HERE_AGENT.md`、`manifest.json` 和 `source_catalog.json`，再处理我的请求。

我的主题是：【在这里填写主题】
目标受众是：【在这里填写受众】
我希望输出：【单条 X 帖文 / 线程 / 选题清单 / 研究简报 / 数据图卡脚本】

请执行：

1. 从目录中筛出最相关的证据源、解释源和必要的观点源。
2. 打开具体原文并重新核验时效、作者、日期、数据口径、研究方法和限制；不要把目录条目或 RSS 地址当作证据。
3. 区分事实、解释、观点和线索，并给每个关键主张提供具体来源链接。
4. 先给读者收益和核心洞见，再给证据；避免标题党、伪因果和夸大确定性。
5. 输出一个可直接发布的版本，以及一份“主张—证据—限制”核验表。
6. 若涉及心理或健康，不做个体诊断或治疗建议；若涉及商业或成长案例，主动说明幸存者偏差和不可复制条件。
